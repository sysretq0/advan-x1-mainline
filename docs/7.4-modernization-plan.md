**Status:** Modernization completed across Series 1–5 (merged through `f1cc338`); `01-clk/0002` (`topckgen`) was intentionally left on existing upstream-style helpers to avoid style-only churn (`f1cc338` dropped `01-clk/0008`). ## 0. Hard guardrails (enforce throughout)

1. **Anchor first** — DONE: `git tag -s tier1-pre-modernize c20c45b`, branch
   `modernize/7.4`. All edits happen on that branch; `main` stays untouched.
2. **Behavior-preserving only** — no silent change to Tier-A-verified register
   bases, IRQ numbers/triggers, clock IDs, voltage/current limits, OPPs,
   thermal thresholds, or `mblock` layout. Exceptions are only the explicitly
   instructed ones: thermal polling/trips (S2), CCF clkbuf (S1),
   CCIF match-data (S5).
3. **One series at a time** — refactor → compile-check → static-check →
   regenerate clean patches for S1 → S2 → S3 → S4 → S5 sequentially. Stop and
   report gate results after each series (S1–2 / S3–5 may be bundled if clean)
   so hardware boot-testing can happen incrementally.
4. **LKML patch hygiene** —
   - every `dt-bindings` YAML patch immediately precedes its consuming
     driver/DTS patch; never mix two subsystems in one binding patch;
   - strip every `Change-Id:` trailer from all `.patch` files;
   - one consistent real `From:` / `Signed-off-by:` identity across the whole
     series (`sysretq0@proton.me`; current git commits use the GitHub noreply
     address and `6bf5e01` still carries a Gerrit `Change-Id:`).
   - GPG-sign commits as `sysretq0` before push.

Correction to the brief: `RUNTIME_PM_OPS()` is a *driver-local* macro in
`include/linux/vfio_pci_core.h`, not a generic kernel helper. Use
`DEFINE_RUNTIME_DEV_PM_OPS()` for our drivers.

### Treewide rules (apply to ALL C drivers)

- Typed allocators: `kmalloc(sizeof(*p), GFP_KERNEL)` → `kmalloc_obj(*p)`;
  `kzalloc(...)` → `kzalloc_obj(*p)`; omit default `GFP_KERNEL`, pass explicit
  gfp only for `GFP_ATOMIC` etc. `devm_kzalloc(dev, sizeof(*p), GFP_KERNEL)`
  → `devm_kzalloc_obj(dev, *p)`; arrays → `*_objs(dev, *p, n)`; flexible arrays
  → `*_flex()`. Cross-check with the two cocci scripts above.
- Scoped cleanup: include `<linux/cleanup.h>`; replace `goto err_unlock`,
  manual `of_node_put()`, `kfree()` ladders with `guard(mutex)(&lock)`,
  `guard(spinlock_irqsave)`, `scoped_guard()`, `__free(device_node)`,
  `__free(kfree)` where they genuinely reduce branching.
- Modern probe/lifecycle: `dev_err_probe()` on all probe errors (especially
  `-EPROBE_DEFER`); `devm_clk_get_enabled()`, `devm_regulator_get_enable()`,
  `devm_reset_control_get_exclusive()`, `devm_pm_runtime_enable()`,
  `device_get_match_data()`, `void` `.remove`; replace `#ifdef CONFIG_PM_SLEEP`
  with `DEFINE_SIMPLE_DEV_PM_OPS()` + `pm_sleep_ptr()`.
- Zero 5.10 BSP anti-patterns: no `static` device/state globals (bind state via
  `devm_kzalloc_obj()` + `dev_set_drvdata()`/`container_of()`); no cross-block
  `ioremap()`/`of_iomap()` peeking (use syscon+regmap, reset controllers or
  `arm_smccc_smc`); no raw `udelay()`/`mdelay()` polling loops
  (`readl_poll_timeout()` / `regmap_read_poll_timeout()`); strict sparse:
  `__iomem`, `__user`, `__le*`, `static` file-locals, proper DMA API with zero
  `virt_to_phys()`; audit every `CLK_IS_CRITICAL` / `GENPD_FLAG_ALWAYS_ON`.

## 3. Mandatory verification gates (per series + final)

A series is **not** complete until all pass with zero errors:

1. **Static & sparse** — `make ARCH=arm64 LLVM=1 W=1 C=1` on every touched `.c`
   object: 0 new warnings, 0 sparse endian/address-space errors.
2. **DT schema** — `make ARCH=arm64 LLVM=1 dt_binding_check` (all added/modified
   YAMLs) and `dtbs_check` for `mediatek/mt6789-advan-x1.dtb`: 0 errors,
   0 warnings.
3. **Patch/style** — `scripts/verify_patches.sh` (100% clean apply, 0 DTS drift)
   + `scripts/checkpatch.pl --strict --codespell` per patch: 0 errors,
   0 non-MAINTAINERS warnings; per-patch compile bisectability.
4. **Runtime torture config (final boot gate)** — optional fragment enabling
   `CONFIG_PROVE_LOCKING`, `CONFIG_DEBUG_ATOMIC_SLEEP`,
   `CONFIG_DMA_API_DEBUG`, `CONFIG_DEBUG_TEST_DRIVER_REMOVE`; one live Advan X1
   torture boot: 0 lockdep splats, 0 DMA-API warnings, clean unbind/rebind,
   LTE/audio/NFC/display working, S3 suspend passing.

## 4. Execution protocol

1. Series 1 in-place on `modernize/7.4`; run gates 1–3 for its touched objects.
2. Report the Series 1 gate table and exact changed patches, then **pause** for
   hardware boot before Series 2.
3. Repeat S2 → S3 → S4 → S5 (S1–2 or S3–5 may be bundled only if clean).
4. Final: generate the torture fragment, hand off the live boot gate, then
   GPG-sign and push for CI.
