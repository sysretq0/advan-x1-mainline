# Curated initramfs kmod manifest (space-separated columns, # comments allowed):
#   <kernel-relative path/to/module.ko>  <CONFIG symbol that must be =m>
#
# Built via Linux Kbuild native single-module targets (all targets in one
# `make` pass so modpost resolves cross-module symbols against vmlinux.o
# without building the 850+ unrelated =m modules in arm64 defconfig).
# Listed in dependency order (helpers before consumers).
